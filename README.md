# 产品介绍
   基于用户群体的需求差异以及使用场景的不同。我们将应用程序分为“呵护模式”（老年人端）和“关爱模式”（家人端）。老年人端：为老年人提供简洁易用的界面，集成天气查询、位置服务、语音交互和健康咨询等功能，通过大字体、语音提示和简化操作满足老年用户需求。家人端：帮助家人远程关注老人状态，提供位置共享、紧急联系、智能对话等功能，实现对老年人的及时关怀与有效沟通。



# 产品特色

## 养生方案一键生成技术
系统实现了基于**多源数据融合**的个性化养生方案生成技术，综合考虑用户健康状况、季节（节气）变化和天气因素。

**核心实现**：
- 多源数据融合：集成用户健康数据、天气 API 数据和节气信息，构建全面的用户情境模型
- 适应性算法：基于规则引擎 + 大模型结合的方式，针对不同健康状况和环境因素智能调整养生建议
- 个性化生成：调用阿里云通义千问模型，通过精心设计的提示词生成针对性养生方案

**技术特色**：
- 天气服务集成：实时获取温度、湿度、空气质量等环境数据，动态调整养生建议
- 季节感知机制：结合中国传统二十四节气与现代健康理念，提供符合季节特点的养生指导
- 健康状态适配：针对不同用户的健康状况，生成差异化养生策略

## 多模态智能交互技术
系统实现了基于阿里云通义千问的多模态智能交互能力，特别优化了老年用户的使用体验。

**核心实现**：
- 模型选择：
  - qwen2-7b 微调模型处理文本交流
  - qwen-vl-max 处理图像理解
- 模型微调：使用 Hugging Face 开源健康医疗数据集及自建数据集进行监督微调（SFT）
- 多模态融合处理：通过阿里云服务统一处理文本和图像输入，提供一致的交互体验
- 适老对话策略：指导模型使用简单易懂的语言，避免专业术语，增强老年用户理解能力

**技术特色**：
- 医疗知识增强：模型通过特定领域知识微调，提高健康医疗咨询的准确性
- 图像理解能力：支持老年用户上传药品、食物等图片进行咨询，系统能识别并提供相关建议
- 连续对话管理：维护对话上下文，确保交流的连贯性和个性化

## 远程关怀技术
系统实现了面向老年用户的远程关爱功能，重点解决紧急情况下的通信需求。

**核心实现**：
- 紧急呼叫系统：集成 Android 系统电话功能，实现一键呼叫紧急联系人
- 权限智能管理：系统在首次使用时申请必要权限，并提供视觉和语音引导

## 生活助手适老化技术
系统全面考虑老年用户的使用习惯和认知特点，实现了一系列适老化设计和功能。

**核心实现**：
- 字体动态调整：全局管理字体大小，用户可根据视力情况一键调整
- 搜索服务优化：集成百度搜索 API，提供简化的搜索结果展示，减少干扰信息
- 日程管理系统：实现提醒功能，支持用药、就医等重要事项提醒

**技术特色**：
- 高对比度界面：所有界面元素保持足够的色彩对比度，提高可读性
- 操作反馈增强：通过视觉、听觉多重反馈，确保用户准确感知操作结果


# 安装指南

### 安装环境要求
- **操作系统**：Android 8.0 (Oreo) 及以上版本
- **API 级别**：26 及以上
- **目标 SDK**：35 (Android 15)
- **编译 SDK**：Android 15
- **Java 版本**：JDK 11

### 安装过程
1. 确保手机设置中允许“未知来源”应用安装  
   - 进入「设置」 > 「安全」 > 开启「未知来源」选项  
     （不同品牌手机路径可能略有不同）
2. 将 APK 文件下载至手机
3. 开启「未知来源」选项
4. 点击下载的 APK 文件
5. 在弹出的安装提示中，点击「安装」
6. 等待安装完成后，点击「完成」或「打开」

### 所需权限说明
应用正常运行需要以下权限：
- **网络通信权限**：连接阿里云通义千问 API、百度地图
- **位置信息权限**：天气服务、区域服务推荐
- **通信权限**：紧急一键拨号功能
- **存储权限**：保存健康数据、访问相册

# 界面设计

### 养生方案一键生成界面
养生方案界面采用**卡片式布局**，直观展示个性化养生建议，以舒缓的绿色系为主，象征健康与活力。

**核心界面元素**：
- 健康数据卡片：展示用户基础健康指标
- 季节养生推荐：根据节气变化提供养生要点
- 天气适应提示：结合实时气象数据的生活建议
- 膳食推荐区域：展示适合老年人的膳食方案

**典型使用流程**：
- 用户进入养生方案页面，输入相关信息
- 系统自动整合用户健康数据、当前季节和天气信息
- 用户点击「生成方案」按钮
- 系统展示个性化养生方案，包括饮食、运动、起居等方面建议

### 智能助手界面
智能助手界面采用**对话式设计**，支持多模态交互，界面简洁友好，专为老年用户优化。

**核心界面元素**：
- 对话气泡区：区分用户和助手消息
- 图片上传按钮：允许用户上传图片进行咨询
- 语音控制面板：调节语音参数，优化听觉体验

**典型使用流程**：
- 用户通过文字或图片提问
- 系统处理输入并生成回复，回复内容自动朗读
- 用户可随时调整语速或暂停
- 对于图片相关问题，系统提供详细图像分析和解答

### 远程关怀界面
远程关爱界面设计简洁醒目，突出紧急联系功能，操作简单直观，适合紧急情况使用。

**核心界面元素**：
- 紧急呼叫按钮：醒目的红色设计，位于屏幕易触及位置
- 联系人列表：展示预设的家人联系方式

**典型使用流程**：
- 用户需要帮助时点击紧急呼叫按钮
- 系统自动拨打预设紧急联系人电话
